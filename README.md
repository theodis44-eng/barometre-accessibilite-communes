# Baromètre de l'accessibilité des sites des communes (septembre 2026)

Lecture automatisée, le 27 septembre 2026, de **5 202 sites de communes françaises de 2 000 habitants
et plus**. Le relevé note ce que chaque site publie en page d'accueil : mention d'accessibilité, lien
« accessibilité », déclaration d'accessibilité complétée, schéma pluriannuel cité.

| Indicateur | Part des sites lus |
|---|---|
| Mention d'accessibilité en page d'accueil | 19 % |
| Lien « accessibilité » depuis l'accueil | 51 % |
| Déclaration d'accessibilité complétée | 22 % |
| Schéma pluriannuel cité | 10 % |

Ce relevé porte sur les informations publiées. Ce n'est pas un audit de conformité RGAA.
